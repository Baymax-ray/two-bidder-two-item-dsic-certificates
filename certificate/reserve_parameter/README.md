# Certified reserve parameter

The final mechanism uses `tau = 83/10000` and the frozen complete seed menu.
`mechanism.py` implements rational reports exactly. The manuscript defines
all real reports and proves DSIC, IR, measurability and capacity, including ties.

Run with Python 3.10 or newer, without optimization:

```
python -B verify_reserve.py
python -B check_implementation.py
```

The first command imports no source calculator. It reconstructs the revenue
polynomial from frozen rational face enclosures, subtracts shared moment
coefficients before bounding the gain, checks exact Bernstein signs for the
unique family optimum and verifies every affine ownership-witness margin
after certifying the whole box's menu branch. Default replay is read-only
and compares the complete derived manifest. `--write` regenerates that manifest.

The second command tests reserve faces, inverse knots, menu boundaries and
witness vertices. Finite checks do not prove continuous incentive quantifiers.
The fixed seed's unique family optimum lies in `(0.008297,0.008299)` and its
family revenue is below `0.87651436`. Neither is an unrestricted auction
optimality claim. Frozen face integrations and the unrestricted upper are
dependencies, not rerun by the parameter arithmetic entrypoint.
