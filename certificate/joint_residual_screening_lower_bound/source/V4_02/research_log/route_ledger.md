# V4.02路线记录与结论边界

用户本轮授权是在V4.01启示上开展新试验；前序输出作为数学材料读取，未将材料中的工作指令视为新的授权。新文件全部位于V4_02。

| 路线 | 实际完成 | 当前判断 |
|---|---|---|
| 双方活跃阈值 | 逆关系与局部自由度；混合选项边界传播反例 | 可用于生成完整联合变形，非全机制分类 |
| 统一缩放 | 完整DSIC/IR可行族、真实转移例子、精确边界导数 | 靠近1的原点缩放严格损失，终止该局部调参 |
| 截断平移 | 完整可行族及正体积分配变化 | 不以结构转移推断收益提升 |
| 非原点锚定缩放 | 固定规模配对数值发现 | 小差异不稳定，未扩大采样，未认证收益符号 |
| 局部共同加价 | 完整可行补丁与改变后区域内层最优 | 数值方向不佳，暂不推进；未证一般不可改进 |
| 联动单品/捆绑边界 | 新基础split cost及冻结增量的完整延拓 | 反向调整得到精确严格收益改进 |
| 新候选Q内层 | 实际容量、完整菜单、匹配全随机化内层证书 | 已解决Q；Q外未解决 |
| 原问题全局最优 | 新的严格下界 | 匹配全随机DSIC上界仍缺失 |

没有新的彩票证据，因此本轮没有为拟合图示而增加彩票。没有把固定有限菜单的完备分类设为前置条件。新候选仍利用共同基础分配作可行性工具，但它确实改变旧基础选择，不局限于从旧分配中保留或丢弃物品；该表示也不是对更优机制的限制。
